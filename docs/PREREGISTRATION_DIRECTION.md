# FOTBCD에서 시간 순서와 사라진 건물 탐지

2026-11-22 KST. 출발 커밋 `595c3bb`. 지난 연구의 FOTBCD test 결과와 방향별 오차를 이미 알고 세운 후속 가설이다. 같은 공식 분할에서 새 seed와 순서 처리 방법을 사전에 고정해 비교한다. 독립된 두 번째 외부 데이터셋은 아니다.

## 질문과 후보

원본 adapted 미세조정의 seed만 바꿀 때 F1과 방향별 픽셀 recall이 얼마나 달라지는가? 시간 순서를 학습 또는 추론 시 대칭화하면 사라진 건물 recall과 F1, precision, 새 건물 recall, LEVIR 성능이 어떻게 바뀌는가?

| 가족 | 학습 | 추론 후보 |
|---|---|---|
| A | 기존 adapted와 동일. seed 42 체크포인트를 해시 검증해 재사용하고 1042, 2042를 추가 | 전→후, threshold 0.5 |
| A+T | 각 seed의 A와 같은 가중치 | 전→후·후→전 확률의 산술평균 또는 픽셀별 최댓값, threshold 0.3/0.4/0.5 |
| S | seed 42, 1042, 2042. 쌍마다 p=0.5로 시점 교환, 이진 GT 유지 | 전→후, threshold 0.5 |
| S+T | 각 seed의 S와 같은 가중치 | A+T와 같은 6개 후보 |

기존 train 명단 1,024쌍, validation 984쌍을 그대로 사용한다. 입력 약 0.5 m/px, 3 epoch, 배치 2, AdamW lr 및 weight decay 각각 1e-4, BCE, 좌우 반전 확률 0.5, 원본 TinyCD 시작 가중치와 픽셀 전처리도 동일하다. 각 seed의 epoch 난수는 seed+1, +2, +3으로 분리한다. S의 시점 교환은 별도 난수열을 사용해 같은 seed A와 S의 표본 순서·좌우 반전 결정을 일치시킨다. epoch 선택은 각 학습 실행의 순방향 threshold 0.5 validation micro-F1 최대, 동률이면 이른 epoch다. 학습은 한 번에 하나만 실행한다.

## 동결과 판정

- A+T와 S+T 각각에서 각 방법·threshold의 validation micro-F1을 seed별로 계산하고 동일 가중치로 평균한다. 평균이 가장 큰 단일 구성을 가족 내 세 seed에 공통 적용한다. 동률이면 평균 결합, 이어서 threshold 0.5, 0.4, 0.3 순으로 고른다. FOTBCD에서는 각 방향 확률을 이진 GT의 원래 격자로 복원한 다음 결합한다. 모든 가족의 역순 validation F1도 기록한다.
- 주 비교의 도전자는 A+T, S, S+T 중 validation 평균 F1 최댓값이다. 동률이면 S, A+T, S+T 순이다. A는 항상 기준으로 둔다. 네 가족의 설정·가중치·manifest 해시와 주 비교를 Git에 동결한 뒤, FOTBCD 공식 test 979쌍에 4가족 × 3 seed 전부를 1회 평가한다. 한 모델·쌍의 방향별 출력을 후보끼리 공유하고 새 test 결과로 선택하지 않는다. 동결한 12개 구성의 같은 설정으로 LEVIR 공식 test 128쌍 전체를 평가한다. 이전 A42 수치와 재현 차이도 보고한다.
- **개선 판정**은 도전자의 사라진 건물 픽셀 recall 3 seed 평균이 A 평균의 2배 이상이고, 도전자의 test F1 평균이 A 평균보다 0.010을 초과해 낮지 않은 경우다. 양쪽을 모두 만족해야 한다. 다른 후보의 test 결과는 설명용이다. 방향별 recall은 기존 전체판 폴리곤을 메타데이터로 일대일 매칭한 뒤 각 클래스 픽셀에서 이진 예측의 적중률로 구한다. 중첩 픽셀은 각각의 분모에 포함한다.
- F1/P/R은 각 seed의 전체 TP/FP/FN 합에서 계산한다. 평균은 3개 seed 점수의 산술평균, 범위는 최솟값·최댓값과 차이다. seed 42의 FOTBCD에서는 동일한 979쌍을 복원추출해 A와 각 도전자 간 F1/P/R·신축/사라진 건물 recall 차이의 95% percentile 구간을 낸다(B=1,000, RNG seed 42). 패치 단위이며 공간 군집과 학습 seed 불확실성은 포함하지 않는다. 최종 F1은 표준 라이브러리로 정수 계수에서 재계산하고 절대 차이 1e-12 이하인지 확인한다.
